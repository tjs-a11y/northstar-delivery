Reefer fuel burn

Burn rate varies by unit and mode — continuous runs higher (often ~0.5–1.0 gal/hr), start/stop (cycle-sentry) lower. Use your own unit's number.

How it works: Run hours = days × hours per day. Gallons = run hours × burn rate. Fuel cost = gallons × diesel price. If the broker will not add a reefer fuel line for a continuous set point, this is the number that proves why you need one. Nothing you enter leaves your device.
