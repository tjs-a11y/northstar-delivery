Trucking Fuel Surcharge Calculation Guide

A fuel surcharge is a contract term, not one universal federal rate. The agreement should identify the diesel-price reference, base price, adjustment schedule and mileage method before a carrier compares the expected surcharge with a settlement.

Important scope note.

The U.S. Energy Information Administration publishes diesel-price data but does not calculate, assess or regulate carrier fuel surcharges.

Read the contract's formula first

Find the base diesel price, the index or region used, the effective date, update frequency, mileage basis, assumed miles per gallon, rounding method and any floor or cap. Two parties can use different formulas and both be following their own agreements.

Choose the correct diesel index and date

If the contract references an EIA series, use the named series and the correct publication week or region. Do not substitute a national average for a regional index or use today's pump price when the agreement specifies a prior week's published figure.

Apply only the agreed mileage and calculation method

Some contracts express the adjustment as a per-mile amount; others use a different table or formula. Apply the agreement's stated base price, fuel-efficiency factor and eligible miles. Treat any example found online as illustrative only unless it matches the written contract.

Reconcile the surcharge with the settlement

Compare the rate confirmation, applicable surcharge table, load mileage, approved changes and final settlement. Record the index date and calculation used so a variance can be discussed with the broker using the same inputs.

Use NorthStar rate-per-mile tools for operating-cost context and Haul Audit to compare agreed load amounts with settlement figures.

Avoid treating the index as a rule

EIA explains that companies use different methods and that it does not recommend or regulate a surcharge formula. The contract controls the calculation. Ask for a written explanation if the agreement does not identify the index, base price or mileage method clearly.
