Driver Qualification File Checklist for Motor Carriers

When the driver qualification rules apply, a motor carrier needs a complete file for each covered driver it employs. A consistent checklist makes it easier to identify missing documents and retrieve records during a review.

Important scope note.

The exact file contents and exceptions depend on the driver and operation. Use the current regulation rather than a generic checklist as the final authority.

Start with the driver's application and identity records

Section 391.51 identifies the application for employment and motor vehicle record among the required file contents. Confirm that the documents belong to the correct driver, match the current licensing information and are legible.

Record the road-test or accepted equivalent

Keep the road-test certificate or the documentation the regulation permits a carrier to accept in its place. If an exception, equivalent qualification or special certificate is involved, retain the supporting record that establishes why it applies.

Track annual reviews and medical records

Build reminders for required motor vehicle record inquiries and annual driving-record reviews. Include medical certification and applicable variance or exemption documentation when required for the driver. Do not assume every driver has the same medical-document path.

Use the correct retention schedule

Section 391.51 generally requires the qualification file to be retained while the driver is employed and for three years afterward. The rule allows specified records to be removed three years after execution, so apply the paragraph-specific rule rather than deleting the entire file on a single date.

Make the file retrievable

Store records under a consistent driver identifier, limit access to authorized personnel and test that the file can be produced promptly. Keep a note of the source and date for each updated document, and follow applicable privacy and security requirements.
